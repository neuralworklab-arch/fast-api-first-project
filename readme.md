# 🚀 My First FastAPI Application

A simple REST API built with **Python and FastAPI**. This is my first FastAPI project, created to learn the fundamentals of building APIs with Python.

## ✨ Features

- Built with FastAPI
- Three simple GET endpoints
- Automatic interactive API documentation
- Clean and beginner-friendly project structure

## 🛠️ Tech Stack

- Python
- FastAPI
- Uvicorn

## 📌 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/` | Returns a welcome message |
| GET | `/welcome` | Returns a welcome message for users |
| GET | `/about` | Returns information about the developer |
